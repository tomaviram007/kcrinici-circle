# עיצוב מחדש של כרטיסיות ההטבות בסגנון קרוסלה פרימיום

## מטרה
להפוך את עמוד ההטבות (`/deals`) לויזואלי ופרימיום יותר על ידי מעבר לכרטיסיות גבוהות בסגנון קרוסלה, עם תמונת כרטיס בראש, רצועת הנחה על התמונה, ופתיחת פרטים בלחיצה על הכרטיס.

## מהות השינוי

```text
עמוד /deals היום:
┌─────────────────────────┐
│  [לוגו]  שם העסק        │
│  • כותרת ההטבה          │
│  • תיאור קצר             │
│  [לקבלת ההטבה]          │
└─────────────────────────┘
רשת של 3 כרטיסים בשורה.

עמוד /deals אחרי השינוי:
        ┌─────────────┐
   ┌────┤  ┌───────┐  ├────┐
   │    │  │ תמונה │  │    │
   │    │  │ 20%   │  │    │
   │    │  │ הנחה  │  │    │
   │    │  └───────┘  │    │
   │    │  כותרת      │    │
   │    │  שם העסק    │    │
   │    │  קטגוריה · תוקף  │    │
   └────┘  └─────────────┘  └────┘
        קרוסלה — כרטיס מרכזי בולט
```

## שלבי מימוש

### 1. מסד נתונים — הוספת עמודת תמונת כרטיס
- הוספת עמודה `card_image_url` (text nullable) לטבלה `public.deals`.
- עדכון ה-RPC `get_public_deals()` כך שיחזיר גם את `card_image_url`, `benefit_type`, `benefit_value` ו-`website_url`.
- עדכון קובץ `src/integrations/supabase/types.ts` בהתאם.

### 2. אחסון — מדיניות העלאת תמונות
- השימוש יהיה באותו bucket `deals` הקיים (`deal-logos/` ו-`deal-images/`).
- וידוא שהמדיניות הקיימת מאפשרת העלאת תמונות למשתמשים מאושרים.
- תמונת הכרטיס תישמר בנתיב `deal-images/{uid}/{timestamp}.{ext}`.

### 3. טופס הצעת הטבה (`src/components/deals/DealSubmitForm.tsx`)
- הוספת שדה העלאת תמונת כרטיס (בנוסף ללוגו העסק הקיים).
- תצוגת תמונה מקדימה בריבוע/מלבן לפני שליחה.
- שמירת `card_image_url` יחד עם שאר הנתונים בטבלה.
- אם אין תמונה — הכרטיס יציג את הלוגו או אייקון קטגוריה כרקע ברירת מחדל.

### 4. פאנל ניהול הטבות (`src/components/admin/AdminDeals.tsx`)
- הוספת שדה "תמונת כרטיס" לטופס העריכה/הוספה.
- אפשרות להזין URL או להעלות קובץ (כמו בלוגו).
- תצוגת תמונה מקדימה ברשימת ההטבות המאושרות.

### 5. עיצוב מחדש של עמוד ההטבות (`src/pages/Deals.tsx`)
- החלפת הרשת (grid) בקומפוננטת קרוסלה:
  - כרטיס מרכזי בולט (scale גדול יותר, z-index גבוה).
  - כרטיסים צדדיים נסוגים (scale קטן יותר, opacity נמוכה יותר).
  - חיצים לניווט ימין/שמאל (RTL).
  - גרירה במגע במובייל.
- עיצוב הכרטיס:
  - תמונה בראש ביחס גובה ~16:10 עם פינות מעוגלות.
  - רצועת הנחה על התמונה בפינה הימנית העליונה (RTL) או על התמונה בצבע זהב/פרימרי.
  - מתחת לתמונה: כותרת ההטבה, שם העסק, קטגוריה, תאריך תפוגה.
  - לחיצה על כל הכרטיס פותחת את פופאפ ההטבה הקיים.
- שמירה על התנהגות הקיימת: סינון לפי קטגוריה וחיפוש טקסטואלי.

### 6. קומפוננטת תג הנחה (`src/components/deals/DealBadge.tsx`)
- שינוי התג מעיגול צהוב לרצועה אופקית שקופה על התמונה.
- תמיכה בשני סוגי ההטבות: אחוז (`20% הנחה`) וייעוץ (`שעת ייעוץ`).
- שמירה על אנימציית כניסה עדינה (fade/slide).

### 7. התאמות RTL ודארק מוד
- כל הטקסטים והחיצים יותאמו לכיוון RTL.
- רקע הכרטיסים יישאר כהה (`bg-card/80`, `backdrop-blur`) כדי להתאים לדארק מוד האתר.
- טקסטים בצבע `foreground` ו-`muted-foreground` לפי המערכת הסמנטית.

### 8. בדיקות ואימות
- בדיקת העלאת תמונה מהטופס והופעתה בכרטיס.
- בדיקת קרוסלה בדסקטופ ובמובייל.
- בדיקת פתיחת פופאפ בלחיצה על כרטיס.
- בדיקת תצוגת fallback כשאין תמונת כרטיס.
- הרצת typecheck ובדיקת build.
